# DESIGN_SYSTEM — MARATHON Tactical

Официальная дизайн-система проекта **MARATHON Tactical**, основанная на разделе 5 [`MARATHON_TACTICAL_MASTER_PROMPT.md`](../MARATHON_TACTICAL_MASTER_PROMPT.md). При наличии этого документа он имеет высший приоритет для визуальных правил и токенов.

---

## 1. Визуальная философия

- **Доля тёмного пространства:** 80–90% экрана занимают почти чёрные поверхности и спокойная, высококонтрастная типографика.
- **Сигнальная дисциплина:** неоновый лайм используется экономно — только для фокуса, активного рабочего пространства и ключевых телеметрических акцентов. Никакого постоянного неонового свечения на всех элементах.
- **Сигнал тревоги:** пурпурно-красный цвет применяется исключительно для ошибок, срочных уведомлений и подтверждения опасных действий (например, перезагрузка/выключение).
- **Тактическая геометрия:** квадратные или слабо скруглённые формы, чёткие `1 px` контуры, асимметричная композиция HUD, сегментированные индикаторы, тонкие панельные разделители.
- **Технические ярлыки:** лаконичные маркировки вроде `SYS / ONLINE`, `WS / 01`, `RUNNER_01` без ущерба для читаемости основной информации.
- **Запрещённые паттерны:** мягкие веб-карточки в стиле SaaS, размытые тяжёлые тени, сплошной glassmorphism-шум, эмодзи вместо иконок, дублирование hex-кодов внутри компонентов.

## 2. Централизованные токены (`ui/tokens/`)

Все визуальные значения должны храниться в **едином месте** (`ui/tokens/`), без разбросанных литералов цвета, отступов, радиусов и длительностей по QML-файлам.

### 2.1. Цветовая палитра по умолчанию

| Токен | Значение | Назначение |
|---|---|---|
| `void` | `#080B0A` | Основной глубокий фон (холст, backdrop, lock screen) |
| `surface` | `#141C18` | Поверхности HUD-панелей, карточек, попапов, полей ввода |
| `signal` | `#C9FF16` | Ключевой лаймовый акцент (активный workspace, focus ring, значимые сигналы) |
| `text` | `#F0F4E8` | Основной текст, заголовки, числовая телеметрия |
| `muted` | `#99A89C` | Вторичный текст, технические подписи, неактивные/disabled элементы |
| `border` | `#354D24` | Чёткие `1 px` линии, контуры и разделители панелей |
| `alert` | `#FF4268` | Ошибки, срочные предупреждения, опасные/деструктивные действия |

*(Примечание: цвета выше являются базовой палитрой проекта и не заявляются как официальные фирменные цвета игры Bungie Marathon.)*

### 2.2. Сетка, размеры и геометрия
- **Базовая сетка:** `4 px` / `8 px` (`4`, `8`, `12`, `16`, `24`, `32`).
- **Границы:** структурная толщина `1 px` (с учётом целочисленного/чёткого рендеринга при масштабировании).
- **Скругления:** `0 px` или минимальный радиус (`2–4 px` централизованно в токенах) для сохранения индустриальной тактической геометрии.

### 2.3. Типографика
- Чёткая иерархия: заголовки / основные значения, рабочий текст, компактные технические ярлыки (микротипографика не должна делать критические данные нечитаемыми).
- **Табулярные цифры (`Font.TabularFigures` / моноширинные цифры)** для часов, процентов громкости/яркости/батареи и индикаторов рабочих пространств, чтобы ширина строк не «прыгала» при изменении значений.
- **Шрифтовая система с проверенной лицензией:** выбор конкретных open-source шрифтов фиксируется с проверкой лицензии (до этапа `D5` не включать проприетарные/непроверенные шрифты).

### 2.4. Анимации и `reducedMotion`
- Короткие целевые переходы (в рамках `100–220 ms`, централизованные длительности в токенах).
- Предпочтение свойствам `opacity` и `transform` без тяжёлых постоянных перерисовок и бесконечных циклов.
- Глобальный флаг **`reducedMotion`** обязателен для всех переходов: при его включении, падении FPS или недоступности графических эффектов интерфейс переключается в статичное или мгновенное представление.

## 3. Контрастность, состояния и адаптивность

### 3.1. Контраст и доступность
- Обычный текст (`text` `#F0F4E8` на `surface` `#141C18` / `void` `#080B0A`, а также тёмный текст `#080B0A` на заливке `signal` `#C9FF16`): контраст **>= 4.5:1**.
- Значимые иконки, активные индикаторы и контуры фокуса: контраст **>= 3:1**.
- Полное управление с клавиатуры (`Tab` / `Shift+Tab`, стрелки, `Enter`, `Escape`) с предсказуемым порядком фокуса.

### 3.2. Обязательные состояния интерактивных компонентов
Каждый интерактивный элемент обязан явно оформлять и проверять следующие состояния:
1. `normal` — спокойное базовое состояние.
2. `hover` — чёткий сдержанный отклик при наведении.
3. `focus` — заметная рамка/индикатор клавиатурного фокуса (`signal`).
4. `active` — состояние нажатия / текущего выбора.
5. `disabled` — приглушённое (`muted`), визуально неактивное состояние без реакции на ввод.
6. `error` — индикация сбоя с акцентом `alert` (`#FF4268`) и кратким пояснением.
7. `loading` — понятное состояние ожидания без блокировки остального shell.
8. `empty` — информативное пустое состояние (например, при отсутствии результатов в Launcher или пустой истории уведомлений).

### 3.3. Адаптивность и устойчивость к данным
- Поддержка разрешений от компактного ноутбука (`1366x768`) до широких мониторов (`2560x1440+`).
- Поддержка системного масштабирования **`100%–200%`**.
- Мультимониторная конфигурация (отсутствие дублирования или потери критических элементов на вторичных экранах).
- Корректная обработка длинных названий окон и приложений (`Text.ElideRight` / контролируемый перенос), кириллицы и Unicode.

## 4. Восемь базовых поверхностей UI

| Поверхность | Назначение и ключевые визуальные правила |
|---|---|
| **Top HUD** | Компактная асимметричная верхняя панель; `signal` только на активном workspace и ключевой телеметрии; `1 px` нижний контур; автоскрытие/минимизация при fullscreen |
| **Workspace Indicator** | Сегментированные тактические блоки/маркеры; явное различие `active`, `occupied`, `empty` и `urgent` (`alert`); поддержка клика и клавиатуры |
| **Launcher** | Высококонтрастная тактическая палитра с мгновенным фокусом в строке поиска, навигацией стрелками/Enter/Escape, отдельным списком безопасных команд и честным `empty`-состоянием |
| **Control Center** | Модульная сетка переключателей и слайдеров (аудио, яркость, сеть, Bluetooth, DND, настройки UI) с явной маркировкой «недоступно» при отсутствии контроллера |
| **Notification Center** | Хронологический стек уведомлений с цветовой полосой срочности (`alert` только для критических), кнопками закрытия/очистки и ограниченной прокручиваемой высотой |
| **OSD** | Лёгкий неблокирующий оверлей громкости/яркости/mute с табулярными процентами, сегментированным индикатором и быстрым auto-dismiss |
| **Session Menu** | Явная сетка действий (`Lock`, `Logout`, `Reboot`, `Shutdown`) с обязательным шагом подтверждения для опасных действий (акцент `alert`) |
| **Lock Screen** | Полноэкранная поверхность `#080B0A`, табулярные тактические часы, поле ввода пароля с контрастным фокусом/ошибкой (Hyprlock или безопасный fallback) |

## 5. Ассеты, лицензии и визуальное ревью

1. **Авторская графика:** собственные геометрические SVG-иконки (`design/icons/`), выровненные по сетке; обои и типографика (`design/wallpapers/`, `design/typography/`) с подтверждённым происхождением и лицензией.
2. **Визуальный контроль (Gate):** ни один визуально значимый компонент нельзя объявлять «визуально готовым» без осмотра отрендеренного скриншота (сначала Windows QtQuick Preview, затем стенд CachyOS) по нормальному, компактному (`1366x768`), HiDPI, overflow и error-сценариям.
