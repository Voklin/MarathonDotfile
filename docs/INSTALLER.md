# Консольная установка MARATHON Tactical

## Запуск

Распакуйте `MarathonDotfile-installer.zip` и перейдите в каталог `MarathonDotfile`. Архив содержит исходники, ассеты и скрипты; установка не требует клонировать Git-репозиторий.

```bash
bash setup.sh
```

Используйте обычного пользователя, без `sudo`. Установщик рассчитан на CachyOS / Arch Linux с Bash и coreutils. Окружение Windows отвергается; Windows Preview запускается отдельно через Python. Предустановленные Hyprland и Quickshell нужны для работы оболочки; отсутствие runtime не мешает скопировать изолированный профиль. Установка не подтверждает совместимость версии Hyprland с синтаксисом профиля.

## Меню

| Пункт | Действие |
|---|---|
| 1 | Установка/обновление, отдельный выбор тем приложений и итоговое подтверждение |
| 2 | План установки без записи |
| 3 | Диагностика из исходного каталога проекта |
| 4 | Восстановление последней резервной копии тем приложений |
| 5 | Восстановление предыдущего профиля с сохранением текущего |
| 6 | Удаление изолированного профиля и команды запуска |
| 7 | Команды запуска и восстановления |
| 0 | Выход |

Enter на вопросе подтверждения означает отказ. EOF завершает меню или отменяет подтверждение; неверный номер возвращает к меню. После ошибки дочернего скрипта выводится его код, сообщение об успешном завершении не печатается.

## Зависимости и первый запуск

Мастер не устанавливает пакеты, AUR-помощники и не обновляет ОС. Просмотрите `scripts/packages-cachyos.txt` и проверьте доступность нужных пакетов на целевой системе; Quickshell проверяется отдельно. Затем выполните `bash scripts/doctor.sh` и проверьте совместимость установленного Hyprland с `hypr/hyprland.conf`.

Для пробного запуска оболочки в существующей тестовой Hyprland-сессии:

```bash
quickshell -p "$HOME/.config/marathon-tactical/shell/shell.qml"
```

Отдельную сессию запускайте вручную из свободного TTY:

```bash
"$HOME/.local/bin/marathon-tactical-session"
```

Мастер не регистрирует сессию в display manager и не переключает текущую сессию. Не запускайте одновременно несколько экземпляров установки или восстановления. Пользовательские симлинки в путях установки не поддерживаются. Из-за путей внутри Hyprland-профиля мастер требует стандартный `XDG_CONFIG_HOME=$HOME/.config`.

## Восстановление

При обновлении исходники копируются в staging-каталог на том же файловом разделе. Только после успешного копирования предыдущий профиль переносится в `~/.config/marathon-tactical-backups/<timestamp>-<unique-id>/`. Настройки, заметки и палитры сохраняются. При ошибке копирования текущий профиль остаётся на месте. Ошибка после замены профиля может потребовать ручного отката; резервная копия сохраняется. Завершение процесса через SIGKILL или отключение питания не обрабатываются Bash-trap.

```bash
# Сначала откатить темы, если они были применены
bash scripts/apply-themes.sh --restore

# Откат профиля: текущий сохраняется, предыдущий копируется обратно
bash scripts/uninstall.sh --restore-backup

# Удаление профиля; резервные копии остаются
bash scripts/uninstall.sh
```

Темы и профиль имеют отдельные резервные копии. Перед удалением профиля восстановите темы, иначе их ссылки могут указывать на удалённые файлы. Если резервной копии профиля нет, `--restore-backup` завершится с ошибкой, сохранив текущую установку. Откат заново создаёт команду запуска сессии с корректным экранированием путей.

## Локальная проверка

```bash
python tests/test_installer.py
python tests/test_contracts_and_assets.py
```

В Windows можно указать Bash через переменную окружения `MARATHON_TEST_BASH`. Тесты создают временный HOME; Windows-ветка заглушает `chmod`, а Linux-среда меню моделируется отдельно. Симлинки проверяются только если ОС разрешает их создание. Эти проверки не заменяют CachyOS: установка пакетов, права исполнения, реальный Hyprland/Quickshell и графическая сессия — `NOT RUN — requires CachyOS`.
