# Консольный установщик MARATHON Tactical

Дата: 2026-11-11. Статус: утверждён пользователем; реализуется локально.

## Назначение и выбранный подход

Пользователь выбрал консольный установщик. Предлагается Bash-мастер с нумерованным меню поверх существующих `scripts/install.sh`, `scripts/apply-themes.sh` и `scripts/uninstall.sh`. Графическое окно потребовало бы дополнительного UI-runtime; ручной запуск нескольких скриптов уже возможен, но не даёт единого сценария установки. Новый мастер переиспользует существующую установку вместо второго независимого механизма копирования.

## Сценарий

Точка входа из скачанного или клонированного проекта: `bash setup.sh`.

1. Показать назначение, целевые пути и состояние окружения Linux / CachyOS / Arch, Hyprland и Quickshell. Версию и совместимость конфигурации проверять на машине пользователя; неизвестную совместимость не выдавать за подтверждённую.
2. Меню: установить/обновить профиль, показать план без записи, выполнить диагностику, восстановить темы приложений, удалить профиль или восстановить его резервную копию, выйти.
3. При установке отдельно спросить, применять ли темы внешних приложений. По умолчанию — нет.
4. Показать итоговый план и запросить подтверждение перед изменениями. Отсутствующие зависимости перечислить с инструкцией установки; не устанавливать пакеты и AUR-помощники автоматически.
5. После установки показать команды запуска, удаления и восстановления. Не запускать новую графическую сессию автоматически.

## Безопасность и границы

- Профиль хранится отдельно в `~/.config/marathon-tactical/`; действующие `hypr`, Quickshell, display manager, службы и удалённый доступ не меняются.
- Темы приложений применяются только после явного выбора, с резервной копией.
- Мастер не запускается от root. Поддерживаются корректная отмена, EOF и ошибочный ввод.
- Обновление сохраняет пользовательские настройки. В рамках задачи проверяется существующий путь резервного копирования и восстановления, включая session helper.
- Никаких фоновых демонов, `curl | bash`, полного обновления ОС или автоматической установки пакетов.
- Подготовка локальных файлов не означает разрешения на новый commit/push: публикация изменений отдельным запросом владельца.

## Проверка

Проверить Bash-синтаксис и сценарии меню, отмену, dry-run без изменений, установку/обновление/откат в изолированном временном HOME, сохранность действующих конфигов. Если локально нет Bash, явно зафиксировать ограничение и выполнить доступные статические проверки. Реальные пакеты, Hyprland, Quickshell и запуск сессии: `NOT RUN — requires CachyOS`.
